# Telegram-бот «Учёт сверхурочных»

Бот каждый день (по умолчанию — кроме воскресенья, дни недели настраиваются)
в заданное время (по умолчанию **20:00**) напоминает отправить количество
отработанных сверхурочно часов. Вы отвечаете числом (`2`, `1.5`, `8 часов`) или
**нажимаете кнопку с часами** — бот сохраняет запись за этим днём. В указанном
дне месяца (по умолчанию **1-е число, 10:00**) бот присылает статистику за
прошедший месяц: по дням, итого, среднее.

Все настройки меняются **кнопками**, команды остаются как запасной вариант.

## Установка

```bash
pip install -r requirements.txt

# токен получите у @BotFather в Telegram
export TELEGRAM_BOT_TOKEN="123456:ABC-your-token"

# часовой пояс (по умолчанию Europe/Moscow)
export BOT_TZ="Europe/Kyiv"   # например

python bot.py
```

Данные хранятся в SQLite-файле `worktime.db` рядом со скриптом
(схема мигрирует автоматически при обновлении кода).

## Кнопки

**Главное меню** (reply-клавиатура, всегда под полем ввода):

| Ряд | Кнопки |
|---|---|
| Меню | 📊 Отчёт · ⚙️ Настройки · ❓ Помощь |
| Часы | 0 · 0.5 · 1 · 1.5 · 2 · 3 |
| Часы | 0.25 · 0.75 · 4 · 5 · 6 · 8 |

Нажатие кнопки с числом = отправка этого числа: часы пишутся за сегодня,
а если бот ждёт ответ после напоминания — за день напоминания.

**⚙️ Настройки** (inline-меню, открывается кнопкой или `/settings`):

- **⏰ Время напоминания** — шаги ±15 мин / ±1 ч, пресеты (08:00, 17:00,
  18:30, 20:00), «✅ Сохранить», «🔄 Сбросить».
- **📅 День отчёта** — кнопки с числами 1–28 (с постраничной навигацией);
  выбор применяется сразу.
- **🌍 Дни напоминаний** — чекбоксы Пн…Вс + пресеты «Без воскресенья» и
  «Только будни»; хотя бы один день обязан остаться выбранным.
- **📊 Текущий месяц / 📁 Прошлый месяц** — статистика одним нажатием.

## Команды бота (необязательно, всё есть в кнопках)

| Команда | Описание |
|---|---|
| `/start`, `/help` | регистрация и справка |
| `/menu` | показать кнопки главного меню |
| `/settings` | меню настроек (кнопками) |
| `/settime 20:30` | изменить время ежедневного напоминания |
| `/setday 5` | изменить день месяца для отчёта (1–28) |
| `/report` | статистика за текущий месяц |
| `/last` | статистика за прошлый месяц |
| `/today 2` | записать часы за сегодня вручную |
| `/set 2026-10-15 3` | записать часы за конкретный день |

Обычное текстовое сообщение с числом после напоминания засчитывается за тот
день, за который бот спрашивал (если ответили позже — за день напоминания, а не
за день ответа).

## Структура проекта

- `bot.py` — handlers команд/сообщений/callback-кнопок, планировщик (APScheduler + cron)
- `menus.py` — генерация всех клавиатур (главное меню, настройки, время, дни)
- `storage.py` — SQLite: пользователи, настройки (включая дни недели), записи,
  «ожидание ответа», состояние меню
- `reports.py` — форматирование месячной статистики
- `test_buttons.py`, `test_flows.py` — тесты (запуск: `python test_buttons.py && python test_flows.py`)

## Развёртывание на сервере

Бот должен работать постоянно (polling). Например:

```bash
# systemd-юнит или просто:
nohup python bot.py > bot.log 2>&1 &
```

## Идеи для развития

- несколько чатов/команд
